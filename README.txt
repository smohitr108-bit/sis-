- script.js: password and interactive features

PASSWORD
riya

RUN LOCALLY
1. Extract the ZIP file.
2. Open the Riya_Secret_Gift folder in VS Code.
3. Open index.html with Live Server, or double-click index.html to open it in a browser.

GITHUB PAGES
1. Upload index.html, style.css, and script.js into the ROOT of a GitHub repository.
2. Open Settings > Pages.
3. Choose "Deploy from a branch", branch "main", folder "/(root)", then Save.
4. Wait for GitHub Pages deployment to finish.

NOTE
The password is a simple front-end lock and is not secure for private or sensitive information.
The font is loaded from Google Fonts when internet access is available.
